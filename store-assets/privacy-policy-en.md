# BlobNote Privacy Policy

BlobNote stores notes, templates, variables, tasks, and settings in the user's browser storage.

The extension does not sell data, share notes with third parties, or send note content to an external server.

The extension uses access to the active tab and page scripting to open its panel, detect the active input field, and insert selected text. Recent clipboard entries are shown only when the user enables that option.

Google Drive sync is disabled in the current store-ready build. Import and export work locally through JSON files.

If the user removes the extension or clears browser data, saved extension data may be removed by the browser.
