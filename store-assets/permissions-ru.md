# Обоснование разрешений

- `storage`: хранение заметок, настроек, задач и переменных в браузере.
- `activeTab`: работа с текущей страницей после действия пользователя.
- `scripting`: подключение панели и модалки базы к текущей странице.
- `contextMenus`: меню быстрых заметок в полях ввода.
- `alarms`: напоминания по задачам.
- `notifications`: показ напоминаний.
- `clipboardRead`: показ последних данных из буфера обмена в панели, только если пользователь включил эту настройку.

В магазинной версии нет разрешения `identity` и нет доступа к `googleapis.com`, потому что Google Drive синхронизация временно отключена.
