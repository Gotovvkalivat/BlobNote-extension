# BlobNote

## Short Description
A fast notes and reply templates extension for inserting text directly into websites.

## Full Description
BlobNote keeps frequent replies, support snippets, tasks, and quick notes close to the page where you work.

Key features:
- notes and templates base with tags, favorites, and search;
- floating panel near the active input field;
- quick search by `/` or keyboard shortcut;
- insert prepared replies, with optional insert-and-send flow;
- optional variables in notes;
- tasks, deadlines, and reminders next to the notes base;
- recent clipboard entries in the panel when enabled by the user;
- light and dark themes;
- Russian and English interface;
- full notes base as a separate tab or over the current website.

Google Drive sync is temporarily disabled in the store-ready build. Import and export are available through local JSON files.

## Privacy
Notes are stored in the browser storage. The extension does not send note content to an external server.
