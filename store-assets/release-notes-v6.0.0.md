# Release Notes 6.0.0

- Renamed the extension to Блокнот / BlobNote.
- Added Russian and English interface language.
- Added first-run onboarding in the popup.
- Reworked light and dark themes for better contrast.
- Added fixed card presets instead of custom color picking.
- Improved embedded base modal, smart search, and floating panel styling.
- Added optional recent clipboard entries in the floating panel.
- Added configurable `/` or `@` search trigger.
- Improved variables toggle so variables disappear from the whole interface when disabled.
- Fixed tag filtering dropdown in the notes base.
- Added separate Firefox build with `background.scripts`.
- Temporarily disabled Google Drive sync for store-ready no-drive builds.
